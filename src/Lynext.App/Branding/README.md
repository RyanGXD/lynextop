# Branding assets

This folder is the home for the final Lynext brand artwork.

- `LynextLogo.png`: optional in-app logo/illustration (to be added).
- `Lynext.ico`: generated by `scripts/build-installer.ps1` for the Windows executable and installer.

The app currently uses a native WPF vector placeholder so the UI remains usable before the final image is chosen. To replace it later, add the approved artwork here and wire it to the UI and icon-generation step. Do not embed personal or copyrighted artwork in a public release unless you have permission to use it.
